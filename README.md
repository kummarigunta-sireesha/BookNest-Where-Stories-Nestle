# BookNest-Where-Stories-Nestle
A user-friendly digital library and book rental platform that allows users to browse, rent, and review books seamlessly. BookNest connects readers with stories and authors in a cozy, intuitive environment.

🚀 Features
📖 Browse & Rent Books
🔍 Search by Genre, Title, or Author
👤 User Login & Registration
💾 Save Favorite Books
⭐ Rate & Review Books
📬 Email Notifications for Rental Confirmations
🗂 Manage Current & Past Rentals
📱 Responsive UI (Mobile + Web Friendly)

🛠 Tech Stack
Frontend: HTML, CSS, JavaScript / React (customize per your stack)
Backend: Node.js / Django / Flask (select your backend)
Database: MongoDB / MySQL / PostgreSQL
Authentication: JWT / Firebase / OAuth
Deployment: Vercel / Netlify / Heroku / Render
